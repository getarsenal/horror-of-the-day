📱 Put it on your iPhone

No app, no account, no settings — about a minute.

  1. Add the Shortcut

    ⬇︎ Add the Shortcut

    Open this page in Safari on iPhone and tap the button — it adds straight to the Shortcuts app, no settings to change.

  2. Make it automatic

    In Shortcuts → Automation → +, choose Time of Day (e.g. 6:00 AM, Daily), pick Run Immediately, and run “Horror of the Day.” Every morning your Home & Lock screen becomes the new horror — hands-free.

  3. Set it as your wallpaper

    Tap Add Action again, search Set Wallpaper, and add it. Leave it using the previous step’s image and turn off Show Preview. Name the shortcut Horror of the Day and tap Done.

  4. Make it automatic

    Go to Automation → + → Time of Day (e.g. 6:00 AM, Daily) → Run Immediately, and run your Horror of the Day shortcut. Done — hands-free every morning.
